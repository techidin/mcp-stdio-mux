# v0.1 Scope

Approved on 10 November 2026. This file is the contract for the first public
release; a change to a criterion is agreed in writing before the code changes.

## Story

As a developer who runs several AI agent apps (Claude Code, Codex, and others),
each with several profiles, I run one command and every stdio MCP server is
shared safely across my sessions, so duplicate MCP processes stop eating my RAM.

## Acceptance Criteria

1. **One command.** `uvx mcp-stdio-mux setup` finds every supported app and
   profile, shows which servers it will route through the mux in which file,
   and applies after one confirmation. `--yes` skips the question.
2. **Detection.** Claude Code (every `~/.claude*` profile and
   `$CLAUDE_CONFIG_DIR`), Claude Desktop, Codex (every `~/.codex*` home and
   `$CODEX_HOME`), Gemini CLI, Cursor, Windsurf, and OpenCode.
3. **Profiles stay isolated.** Profiles with the same name share backends across
   apps (`~/.claude-work` and `~/.codex-work`); differently named profiles never
   share unless the user maps them to one domain in the config file. Different
   declared credentials never share.
4. **User configs are safe.** Every file is backed up before it changes, written
   atomically, and re-checked after writing. A second `setup` changes nothing.
   `undo` restores the original bytes when the app has not touched the file
   since, and unwraps in place when it has. HTTP servers are never touched.
5. **Lighter shims.** The per-session shim uses at least 50% less memory than the
   internal runtime it replaces (14 MB `phys_footprint`, measured 10 November
   2026), measured the same way. All ported tests pass.
6. **Agent skill.** `SKILL.md` lets a user ask an agent to "share my MCP
   servers": the agent previews, applies after consent, verifies with
   `mcp-stdio-mux status`, and knows how to undo.
7. **Release.** macOS and Linux CI pass on Python 3.11 and 3.13, the wheel
   installs into a clean environment, the private-data scan is clean, and the
   README carries before/after numbers measured on a real machine.

## Out of Scope

Windows; project files such as a repository's `.mcp.json` (they belong to a
team); HTTP and SSE servers; request replay after a backend crash; a dashboard;
re-wrapping new servers without a command (re-run `setup` or ask the skill).

## Definition of Done

Each criterion has evidence in the release pull request; CI is green; the
owner makes the repository public and registers the PyPI trusted publisher.
